Counting rules and interpretation
  • Equal ranks: dates in the same rank group contribute no vote against each other. Ranked dates beat omitted dates; omitted dates beat explicitly rejected dates. Omitted dates are tied with each other, and rejected dates are tied with each other at the bottom.
  • Victory strength: descending winning margin, then descending winning votes. Exact ties use the original option order, first the winner then the loser. This matches Humans’ RankedChoiceCounter.
  • Finishing order: repeatedly take a date with no incoming locked edge among the remaining dates. If multiple dates qualify, use original option order. The page reports when this fallback is needed.
  • Rejection is not a veto: it places a date at the bottom of that ballot. It does not remove the date from the election.
  • Percentages: general charts use all 97 ballots. Matrix percentage mode uses only ballots that distinguish the two dates. First-choice shares split one vote equally among tied first choices.
  • Scope: this export is the Asociado vote, not the earlier 948-response attendee survey. It does not contain the eligible electorate size, so no turnout percentage is inferred. The export alone does not establish whether voting was formally closed.

A distinction from the earlier explainer: the voting-method page describes omitted and rejected dates as tied. Humans’ implemented count distinguishes them as described above. This page follows that implementation and matches the supplied results matrix. The distinction changes 6–12 September vs 5–11 July from 64–25 to 64–26; it does not change the winner or finishing order.
